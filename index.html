4-Bit Adder-Subtractor

One adder, two operations. With mode input M = 0 it computes A + B. With M = 1, each XOR gate flips a bit of B and M also feeds the first carry-in, so the adder computes A + (NOT B) + 1, which is A − B.

How it works

XOR as a controlled inverter

B ⊕ 0 = B and B ⊕ 1 = NOT B. When M = 0 the adder sees B unchanged. When M = 1 it sees the one's complement of B.

Carry-in supplies the +1

M also drives the carry-in of bit 0. In subtract mode that adds 1, giving A + NOT B + 1, the two's-complement form of A − B.

Reading the carry out

Add: Cout = 1 means the sum is above 15. Subtract: Cout = 1 means no borrow (A ≥ B). Cout = 0 means the answer is negative and S shows it in two's complement.
